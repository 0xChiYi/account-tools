## 🌟 核心特色

- 🔒 **隐私绝对安全**：纯前端 HTML5 + Web Crypto API 本地计算，**没有任何后端接口，数据零上传**。
- ⚡ **即开即用**：托管于 GitHub Pages，全球 CDN 加速，支持 PC 与 mobile 端自适应。
- 🎯 **Degen 极速体验**：支持一键格式化、自动兼容多段分隔符、批量生成并一键复制。

---

## 🚀 已上线工具

### 1. ⚡ 账号格式化转换器 (`account_formatter.html`)
- **适用场景**：批量清洗、重组导入的账号文本。
- **功能特点**：
  - 支持 **4段式** (`账号----密码----辅助邮箱----2FA`) 与 **3段式** (`账号----密码----2FA`) 自由切换。
  - 自动识别格式并高亮转换，支持一键复制代码。

### 2. 🔑 2FA 动态验证码生成器 (`2fa.html`)
- **适用场景**：批量生成谷歌 Authenticator 6 位动态验证码。
- **功能特点**：
  - 支持直接粘贴纯 2FA 密钥，或直接粘贴整行 `账号----密码----2FA` 复杂文本（智能提取末尾密钥）。
  - 内置 Base32 容错与字符映射矫正（自动处理非标准字符）。
  - 30 秒自动刷新倒计时 + 进度条，支持一键批量复制。
